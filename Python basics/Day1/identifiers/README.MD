Identifiers in Python

Rules for Writing Identifiers
Can contain:
Letters (A-Z, a-z)
Digits (0-9)
Underscore (_)
Example: name, age_1, user_name

Cannot start with a digit
1name is invalid
name1 is valid

Case-sensitive
name, Name, and NAME are all different identifiers

Cannot be a Python keyword
if, while, class, def, etc. cannot be used as identifiers

No special characters
Symbols like @, #, $, %, &, * are not allowed
